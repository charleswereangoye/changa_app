## Measurement method and limits

Source: coverage/lcov.info, generated by flutter test --coverage.

Coverage is the number of DA line entries with a positive hit count,
divided by the total measured DA line entries. Duplicate entries for
the same source file and line are counted once.

firebase_options.dart is excluded by policy; it was already absent
from this LCOV file. No additional files were explicitly excluded.

These percentages describe files represented in LCOV. They do not
prove coverage of every application file. Some runtime files are absent,
including main.dart, app.dart, the router, SplashPage, DashboardPage,
and AddEditChorePage.
