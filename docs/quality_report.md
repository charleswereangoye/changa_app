## Measurement method and limits

Source: coverage/lcov.info, generated by flutter test --coverage.

Coverage counts unique source-file and line pairs from LCOV DA entries.
A line is covered when its hit count is positive. Duplicate entries for
the same source file and line are counted once.

firebase_options.dart is excluded by policy. It was already absent
from this LCOV file, so the script removed no generated Firebase files.

The percentages describe files represented in LCOV and do not establish
coverage of every application file. There are 23 lib/ Dart files absent
from this snapshot. The saved coverage summary lists them.

Absent runtime files include main.dart, app.dart, app_router.dart,
home_shell.dart, SplashPage, DashboardPage, and AddEditChorePage.
Some absent files are abstract contracts, constants, or enums.
